# C-Programming

Coursework for the C Programming / Operating Systems class (Batch 39C).

## Labs

| Lab | Folder | Description |
|-----|--------|-------------|
| Lab 1 | `Lab-1-Compilation` | The compilation process: preprocessing, assembly, object files, linking. |
| Lab 2 | `Lab-2-Process-Lifecycle` | Processes in C: PIDs, sleeping, exit codes, user input. |
| Lab 2.1 | `Lab-2.1-ELF-and_Linking` | C libraries, static vs dynamic linking, ELF executable structure. |
| Lab 3 | `Lab-3-Data-Types` | Data type sizes and memory layout (stack, heap, data, BSS). |

Each lab folder has its own `README.md` with details on the files and how to compile and run them.
